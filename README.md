# Sapphire Coding Club

Welcome to Sapphire Coding Club! 💻✨

A fun little corner of the internet I built to share what we're learning about code in Lagos.

### What is this?
This is our club's website. I started it in Week 2 with just basic HTML, and by Week 10 it became this — a clean, responsive, multi-page site that actually works on both phone and laptop.

### Inside the site
- **Home (index.html)** - What the club is about + our weekly schedule
- **About (about.html)** - Who's behind the club and why I started it
- **Style (styles.css)** - All the styling, flexbox and mobile-first design

### Built With
- HTML5 (semantic tags - header, nav, main, section, footer)
- CSS3 (Flexbox, media queries, variables)
- Small details that matter - alt text, table captions, aria-labels, no sideways scroll
