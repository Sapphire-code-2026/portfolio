Our Projects

This is what we've been building at Sapphire Coding Club. Nothing fancy — just small, real projects that taught us how websites actually work. From Week 1 structure to Week 10 responsive design.

Project 1: Club Profile Site

Our first site. I learned how to structure a page properly — header, nav, main, section, footer. It's responsive and doesn't scroll sideways on mobile.

  • Used: HTML5 semantic tags
  • Learned: DOM tree, nesting, landmarks

Project 2: Schedule Table

We added our weekly club schedule using a table. Added caption and th for accessibility, and wrapped it so it scrolls on small phones instead of breaking.

  • Used: table, caption, thead, tbody
  • Learned: Accessibility matters

Project 3: Responsive Styling

This was Week 6 to 10. I rebuilt the CSS with variables, Flexbox, and media queries. Same code works at 360px, 768px, and 1200px.

  • Used: CSS variables, Flexbox, media queries
  • Learned: Mobile-first design
